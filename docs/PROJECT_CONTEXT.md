# University Management System (UMS)

## Project Overview

University Management System (UMS) is a full-stack web application developed as a Database Management System Laboratory project.

The system is designed to digitize and manage the academic and administrative activities of a university through a centralized database.

This project will be developed following professional software engineering practices, including proper documentation, version control, modular architecture, and scalable code.

---

# Project Goal

Build a modern, secure, scalable and user-friendly University Management System.

The application should support:

- Student Management
- Teacher Management
- Department Management
- Course Management
- Enrollment
- Attendance
- Examination
- Result Processing
- Payment Management
- Timetable Management

Future AI features will also be integrated.

# Database

The database will be designed and implemented manually in MySQL.

No ORM will be used.

No MongoDB.

No Firebase.

No Supabase.

The backend will communicate directly with MySQL.
